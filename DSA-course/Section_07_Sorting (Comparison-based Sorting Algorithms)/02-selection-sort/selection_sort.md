Selection Sort. 

Suppose we have this array = { 5. 3. 4. 1. 2}

We know that this whole array in unsorted. We will first find the min value from this array which is 1. We will move 1 to the correct position.
Now we have one element that is sorted and rest of the elements unsorted.
We will find the next min number which is 2 and we will move it to the sorted part. 

We will repeat this until we have the sorted array.
