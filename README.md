# learning_DSA

Data Structures & Algorithms study repo. Concepts are learned from Abdul Bari's *Data Structures and Algorithms* Udemy course (implemented in **C and C++**), and problem-solving practice follows the **NeetCode roadmap** on LeetCode / NeetCode.io.

## Timeline

- **30-40 days** to finish all 28 sections of lecture videos.
- Some NeetCode roadmap questions are attempted alongside the lectures as related topics are covered.
- After the lectures are done, remaining time goes into focused practice through the NeetCode roadmap.

## Repo structure

```
DSA-course/                      Abdul Bari course, one folder per section
  Section_NN_Topic/
    Programming/
      C/                         C implementations for this section
      Cpp/                       C++ implementations for this section
    Eraser-io/                   Diagrams/images exported from eraser.io
    Notes/                       Written notes for this section

Roadmap-DSA/                     NeetCode roadmap reference (image + notes)

archive/                         Earlier LeetCode practice solutions & notes
```
